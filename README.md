# 🌼 Onam Odyssey

**Maveli's Kasavu Quest — Kerala Edition**

A lightweight, mobile-friendly browser game inspired by Onam. The game is built with a single self-contained `index.html`, using HTML, CSS and JavaScript Canvas with no external dependencies.

## 🎮 Gameplay

### Level 1 — Climb
- Maveli climbs the rising brick paths.
- Jump over rolling coconuts.
- Collect umbrella-shaped power points.
- Reach the golden arch to enter Level 2.

### Level 2 — Giant Stomp
- Maveli reaches the plain ground.
- A giant foot becomes the main obstacle.
- Run sideways to escape.
- Use **2 ☂ power** to attack.
- Hold **Shift / Defend** to protect Maveli.
- Reach the finish area and complete the Onam Odyssey.

## 🕹️ Controls

- `A / D` or `← / →` — Move
- `W / ↑ / Space` — Jump
- `F` — Attack in Level 2
- `Shift` — Defend in Level 2
- Mobile — On-screen controls

## 🌿 UI/UX

- Kerala green and Kasavu-gold theme
- Onam-inspired decorative elements
- Clear lives, power, level and score HUD
- Mobile-first touch controls
- Pause/resume control
- Responsive layout

## 🚀 Run

Open `index.html` in a modern browser.

## 🌐 GitHub Pages

Go to **Settings → Pages**, select the main branch and `/ (root)` folder, then save. GitHub Pages can then host the game as a playable website.
