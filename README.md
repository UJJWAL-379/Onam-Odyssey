# 🌼 Onam Odyssey

## 👑 Maveli's Kasavu Quest — Kerala Edition

A festive, lightweight browser game inspired by **Onam, Maveli, Kerala culture, and traditional celebrations**.

Maveli must climb the festive paths, avoid rolling coconuts, collect umbrella power, and then survive a giant stomp in the second level. The game is designed to be easy to download, run, share, and host using GitHub Pages.

> 🎮 **No installation • No backend • No database • No API key • No external libraries required**

---

## 🎮 Play the Game

If GitHub Pages is enabled for this repository, the game can be played directly in a browser.

# 🕹️ How to Play

## 🌿 Level 1 — The Maveli Climb

Maveli begins at the bottom of the festive brick paths.

Your goal is to:

1. Move across the paths.
2. Jump between the rising platforms.
3. Avoid the rolling coconuts.
4. Collect the glowing **☂️ umbrella power points**.
5. Reach the golden arch.
6. Continue to Level 2.

### 💡 Tip

Collect as much umbrella power as possible. You will need it for Level 2.

---

## 👣 Level 2 — The Giant Stomp

After reaching the plain ground, Maveli faces a huge giant foot.

Your goal is to:

1. Keep moving sideways.
2. Avoid the giant stomp.
3. Use your collected umbrella power wisely.
4. Spend **2 ☂️ power** to perform an attack.
5. Hold **Shift / 🛡️ Defend** to block an incoming hit.
6. Reach the finish area.
7. Complete the **Onam Odyssey**! 🌼

|---|---|
| `A` / `←` | Move left |
| `D` / `→` | Move right |
| `W` / `↑` | Jump |
| `Space` | Jump |
| `F` | Attack in Level 2 |
| `Shift` | Defend in Level 2 |

## 📱 Mobile

Use the on-screen buttons:

- ◀ **LEFT** — Move left
- **RIGHT ▶** — Move right
- ⤴ **JUMP** — Jump
- ☂ **ATTACK** — Attack when you have enough power
- 🛡 **HOLD TO DEFEND** — Defend against the stomp
- ↻ **RESTART LEVEL** — Restart the current level

# ☂️ Understanding Umbrella Power

Umbrella power is one of the most important resources in the game.

### Collecting power

In Level 1, collect the glowing umbrella-shaped points to increase your power.

### Attacking

In Level 2:

**2 ☂️ power = 1 umbrella attack**

Use the attack when you need to fight back or create an opportunity to escape.

### Defending

Hold **Shift** on a keyboard or the **DEFEND** button on mobile to protect Maveli from an incoming attack.

> 💡 Save enough power for Level 2 instead of using it carelessly.

# 🌐 How to Host the Game with GitHub Pages

GitHub Pages allows the game to be opened as a normal website.

### Steps

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select the `/ (root)` folder.
7. Click **Save**.
8. Wait for GitHub Pages to deploy the site.
9. Open the generated Pages URL.

Because the main game is `index.html` at the repository root, GitHub Pages can serve it directly.

# 🐛 Troubleshooting

### The game does not open

Make sure you are opening the correct file:

```text
index.html
```

Try Chrome, Edge, Firefox, or Safari.

### Keyboard controls do not work

Click/tap the game page first and make sure the browser window has focus.

### Mobile controls do not respond

Reload the page and tap the on-screen controls directly. Use a modern mobile browser.

### GitHub Pages is not showing the game

Check:

1. Repository is accessible.
2. **Settings → Pages** is configured.
3. `main` is selected as the deployment branch.
4. `/ (root)` is selected as the folder.
5. `index.html` is present in the repository root.
6. Give GitHub a little time to finish deployment.
