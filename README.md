# 🌼 Onam Odyssey — Maveli Run

**ONAM.exe | IEEE SB VJCET**

A Kerala/Onam-themed endless runner where **Maveli** races through a festive road, changes lanes, jumps over obstacles, and collects flowers to build a Pookalam. The project is built as a lightweight browser game with Phaser and Vite.

## ▶️ Play Online

**GitHub Pages:** https://UJJWAL-379.github.io/Onam-Odyssey/

If the link is temporarily unavailable after a push, check the repository's **Actions** tab and wait for the Pages deployment to finish.

## 🎮 How to Play

- **← / A:** move left
- **→ / D:** move right
- **↑ / W / Space:** jump
- **Mobile:** swipe left/right to change lanes; swipe up to jump
- Avoid festival barricades, coconuts and trains.
- Collect the Onam flowers in sequence: **Thumba → Chetti → Jamanthi**.
- Your score and speed increase as the run continues.
- The run ends when Maveli collides with an obstacle while on the ground.

## 🌺 Why It Fits Onam

The gameplay is intentionally tied to Kerala's festival culture rather than using Onam only as a visual skin:

- Maveli is the playable hero.
- The road is styled as an Onam/festival route.
- Pookalam flowers are collectibles and a progression sequence.
- Kerala-inspired colours, greenery, gold accents and festive obstacles shape the visual identity.
- The game is designed around a simple, immediately understandable runner loop so judges can play it within seconds.

## 🛠️ Technology

- **Phaser 3** for game rendering, input and scene management.
- **Vite** for development and production builds.
- JavaScript ES modules with a modular scene/entity structure.
- GitHub Actions + GitHub Pages for web deployment.
- No account, analytics or server-side game data.

## 💻 Run Locally

Requirements: **Node.js 20+**.

```bash
npm install
npm run dev
```

Then open the local Vite address shown in the terminal, normally `http://localhost:5173/`.

For a production check:

```bash
npm run build
npm run preview
```

## 🌐 Deployment

The repository contains a GitHub Actions Pages workflow. Every push to `main` builds the Vite project and deploys the generated `dist/` folder.

If GitHub Pages has not been configured yet, set **Settings → Pages → Source → GitHub Actions** in the repository.

## 🎥 Competition Screen Recording

A screen recording is a **manual submission item** and is not generated by the repository itself. See `SUBMISSION_CHECKLIST.md` for the recommended 60–90 second recording sequence.

## 📜 Competition Compliance

The ONAM.exe guidelines require a public GitHub repository containing a playable game, complete source/project files, a gameplay screen recording, and a short game write-up. They also require teams to respect third-party licenses and not submit another person's complete work as their own.

This repository therefore includes project documentation and credits; the **screen recording and final submission form still have to be completed by the team**.

## 🔒 Privacy

There is no account system, server-side player profile or analytics in the game.
