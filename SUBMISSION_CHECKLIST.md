# ONAM.exe Final Submission Checklist

Use this checklist immediately before submitting the form.

## Required by the competition

- [ ] Repository is **public** and accessible.
- [ ] Repository contains the complete game source code and required project files.
- [ ] The online game opens from the submitted playable-game URL.
- [ ] Gameplay has been screen-recorded and the recording is ready to upload/provide.
- [ ] Short game write-up is ready.
- [ ] GitHub repository link is copied correctly into the ONAM.exe submission form.
- [ ] Playable-game link is copied correctly into the form.
- [ ] Screen recording is uploaded/provided as instructed by the form.
- [ ] Game details and team information are completed.

## 60–90 second recording plan

1. **0–10 s:** Show the title screen and start the game.
2. **10–35 s:** Demonstrate left/right lane switching and jumping.
3. **35–55 s:** Collect multiple flowers and show the Pookalam sequence/progress.
4. **55–70 s:** Show increasing speed and at least one close obstacle dodge.
5. **70–90 s:** Intentionally hit an obstacle, show the score/game-over screen, then briefly show the repository or playable link if useful.

Record the actual gameplay rather than a static code walkthrough. Keep controls, visuals and the Onam connection easy for a judge to understand.

## Judge-ready write-up

**Game:** Onam Odyssey — Maveli Run

**Idea:** A fast, accessible endless runner that turns familiar Onam elements into gameplay. Maveli runs through a Kerala-inspired festival route, avoids obstacles and collects flowers to build a Pookalam.

**Gameplay:** The player switches between three lanes and jumps over hazards. The run becomes faster over time, while flower collection rewards the player and follows the Thumba → Chetti → Jamanthi sequence.

**Onam connection:** Maveli, Pookalam flowers, Kerala-inspired scenery, festive colours and cultural references are integrated directly into the game loop and visual design.

**Technology:** Phaser 3, Vite, JavaScript ES modules, and GitHub Actions/GitHub Pages.

**Originality:** The project is an original team implementation. Open-source development tools are used under their applicable licenses, with attribution recorded in `CREDITS.md`.
